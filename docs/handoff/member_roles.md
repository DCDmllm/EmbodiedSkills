# 成员分工

本文档用于记录 EmbodiedSkills 项目的当前协作分工。成员名先使用 A/B/C/D/E/F 占位，确定真实成员后可直接替换。

## 分工表

| 成员 | 主要职责 | 交付内容 |
| --- | --- | --- |
| A | 代码完善、框架维护、部分仿真实验 | runtime/RL/reward/skill 代码迭代，关键 bug 修复，核心仿真实验复现与记录 |
| B | 仿真实验 | 与 C 共同负责 RoboTwin 仿真实验、日志整理、失败 case 归因、成功率统计和实验表格更新 |
| C | 仿真实验 | 与 B 共同负责 RoboTwin 仿真实验、日志整理、失败 case 归因、成功率统计和实验表格更新 |
| D | 真机实验 | 真实机械臂环境部署、相机与动作接口调试、真机任务执行与视频/日志采集 |
| E | 论文写作与图表 | 与 F 共同负责论文写作、实验结果整理、系统图/流程图/案例图和补充材料 |
| F | 论文写作与图表 | 与 E 共同负责论文写作、实验结果整理、系统图/流程图/案例图和补充材料 |

## 协作接口

- A 维护代码入口、配置和实验脚本，向 B/C/D 同步可运行版本、运行命令和已知问题。
- B/C 输出仿真实验日志、结果表格、失败样例和可复现实验配置。
- D 输出真机实验视频、传感器/动作配置、运行日志和真实环境限制说明。
- E/F 汇总实验结论、撰写论文内容，并把需要补跑的实验或缺失图表反馈给 A/B/C/D。

## 建议节奏

- 代码版本更新后，A 在实验群或 issue 中同步变更点、配置文件和推荐命令。
- 仿真实验按任务、模型、配置三类维度记录，B/C 每轮实验保留 run id、日志路径和结果表格。
- 真机实验由 D 记录硬件配置、相机配置、失败原因和可复现操作步骤。
- 论文材料由 E/F 统一收口，图表数据来源需要能追溯到对应仿真或真机实验记录。
